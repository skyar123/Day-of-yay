# Day of Yay 💛

A love story, set inside a city's history.

Mobile-first walking tour app for Maggie & Hilary's downtown Asheville celebration. Eight stops covering Pack Square, the Register of Deeds, Art Deco architecture, the YMI Cultural Center, the Flatiron Building, Grove Arcade, the Basilica of Saint Lawrence, and the Urban Trail.

## Stack

- React 19 + Vite
- CSS custom properties (no external UI library)
- Google Fonts: Fraunces (serif) + DM Sans

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
